# Architecture Decisions

This directory contains architecture decision records (ADRs) for significant technical choices.

## Naming

Use a four-digit sequence followed by a short kebab-case title:

```text
0001-short-title.md
```

Never reuse a sequence number. Superseded decisions remain in the repository as historical context.

## Template

```markdown
# 0001: Short title

## Status

Proposed

## Context

What problem or constraint requires a decision?

## Decision

What was decided?

## Consequences

What are the positive and negative effects of this decision?
```
