# Finish Issue

1. Read the issue and confirm its acceptance criteria and dependencies.
2. Inspect Git status, commits, and the complete implementation diff.
3. Check that behavior, tests, and affected documentation satisfy the issue without unrelated changes.
4. Run the verification commands documented in `AGENTS.md`.
5. Report whether the issue is ready for a pull request, with concrete blockers or remaining work.

Do not commit, push, create a pull request, merge, or modify GitHub.
