# Start Issue

1. Read the issue, comments, priority, dependencies, and linked pull requests with `gh`.
2. Inspect Git status, relevant commit history, code, tests, and documentation.
3. Confirm the issue is open, still valid, unblocked, and not already being implemented.
4. Summarize the goal, acceptance criteria, dependencies, affected areas, risks, and verification.
5. Produce a focused implementation plan consistent with the repository instructions.

Do not modify GitHub, create or switch branches, or implement the issue unless explicitly requested.
