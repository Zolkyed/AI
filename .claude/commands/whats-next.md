Determine what should be implemented next from this repository's GitHub issues.

1. Inspect open issues, priorities, dependencies, linked pull requests, and milestones with `gh`.
2. Inspect recent commit history to understand completed work, active areas, and whether each issue remains relevant.
3. Exclude work that is blocked, already in progress, duplicated, or completed by existing commits.
4. Recommend one ready issue based on priority, dependency order, and commit history. Include the rationale and concise scope; if none is ready, report the blockers.

Do not modify GitHub, Git, or repository files.
